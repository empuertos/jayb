Buod ng Derby Matchmaker Pro System
​Layunin: Isang web application na ginawa para sa mga derby organizer upang ma-automate ang matching ng mga manok, paggawa ng fight schedule, at pag-upload ng HD program online gamit ang QR Code.
​Mga Main Features:
​Event Setup & Rules: Pag-set ng pamagat, venue, petsa, derby format (3 hanggang 6-cock), max weight gap, at rest buffer.
​Roster Management: Mabilis na pagdaragdag ng entries sa pamamagitan ng Excel/CSV upload o manual input, na may auto-save capability sa browser.
​Smart Matching Engine: Awtomatikong pinapares ang mga manok batay sa pinakamalapit na timbang at sinusunod ang mga tuntunin sa pahinga at timbang.
​Cloud Upload & QR Code: Ginagawang image file ng html2canvas ang fight program, ina-upload ito sa ImgBB, at gumagawa ng QR Code para madaling ma-view ng mga bisita sa kanilang mobile phone.
​Teknolohiya: HTML5, CSS3, Vanilla JavaScript, SheetJS (xlsx), html2canvas, QRServer API, at ImgBB API.
